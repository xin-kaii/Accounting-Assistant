# 任务板

> **怎么用**：每天 20:30 站会时对着这份清单过一遍，做完的打 `[x]` 并在后面写上日期。
> 不用飞书/Notion——三行内能说清的事，多开一个平台就是多一个没人更新的地方。
>
> 打勾标准：**能演示**，不是"代码写完了"。写完但跑不起来的不算。
>
> **合并门槛（硬规则）**：验收不达标的东西留在自己的分支上，`main` 只接受跑过验收的代码。
> 例：B 的 `mock_llm` 验收线是「10 句对 8 句」，实测 6/8，就不该合进 main。
> 宁可 main 少一个功能，不可 main 上有一个算错的数字。
